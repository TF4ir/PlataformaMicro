# UX & Usability Skill

## 1. Overview & Role
Guides interaction design and cognitive ergonomics for 5th year secondary students (ages 16–17) and educators.

## 2. Core Usability Guidelines
- **Cognitive Load Minimization**: Design microlearning sessions capped at 3–5 minutes (bite-sized chunks) to sustain attention and prevent fatigue.
- **Empathetic Microcopy**: Never display negative labels such as "Fallo crítico" or "Estudiante en riesgo". Frame opportunities constructively: "Momento ideal para repasar", "Consolida este concepto".
- **Mobile-First Accessibility**: Ensure touch targets are at least $44 \times 44$ px, with high contrast meeting WCAG 2.1 AA standards.
- **Teacher Dashboard Ergonomics**: Present KC mastery aggregations with clear color coding without overwhelming teachers with raw parameter weights.
- **Phase 0 Guardrail**: During Phase 0, all UI design work is strictly conceptual and limited to documentation (`docs/ux/`). No UI components may be written to `apps/web/`.
